# أساسكو ماكس | ASASKO MAX

الموقع التعريفي الرسمي لشركة **أساسكو ماكس** المتخصصة في حلول التشطيبات المعمارية في المملكة العربية السعودية:
- **الدهانات الداخلية والخارجية**
- **أرضيات الإيبوكسي التجارية والصناعية والمواقف**
- **تشطيبات الواجهات والبروفايل المعماري**

## التقنيات المستخدمة
- HTML5 / CSS3 / JavaScript (Vanilla)
- تصميم متجاوب بالكامل لجميع الشاشات والهواتف (Responsive Design)
- يدعم اللغة العربية واتجاه RTL
- متوافق مع الاستضافة على Vercel و GitHub Pages

## النشر على Vercel
المشروع عبارة عن موقع ثابت (Static Site) بمجرد ربط المستودع في Vercel يتم نشره تلقائياً دون الحاجة لأي إعدادات خاصة.
